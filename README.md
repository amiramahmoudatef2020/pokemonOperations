# pokemonOperations

for running locally
start with npm install then npm run dev

## Scope & Time Investment

I spent around **16 hours end-to-end** building and refining this project, including:

- Setting up a **Next.js + TypeScript + React Query + Tailwind** base.
- Implementing **two Pokémon list views** (pagination + infinite "Load More") with proper caching, error handling, and skeleton loading.
- Building a **fully typed detail page** using **React Server Components (RSC)**.
- Adding a **global Error Boundary + Suspense**, route-level loading/error for the detail page, and removing all `any` types.
- Ensuring the UI is **responsive and clean across devices** (desktop, tablet, mobile).

A big portion of this time was focused on **type-safety, architecture, and polish**, not just making something that “barely works”.
